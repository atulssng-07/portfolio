# Atul Kumar Singh Portfolio

Modern, responsive portfolio website for Atul Kumar Singh, focused on Data Analyst, Business Intelligence, reporting, Python, SQL, Power BI, and ERPNext roles.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React icons

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm run start
```

## Customize

Portfolio content lives in `data/portfolio.ts`. Update profile links, project details, skills, certifications, and contact placeholders there.

The hero and Open Graph image is `public/atul-analytics-hero.png`. The resume download target is `public/atul-kumar-singh-resume.pdf`.

## Deploy to Vercel

1. Push the repository to GitHub.
2. Import the project in Vercel.
3. Keep the default Next.js build settings.
4. Deploy.
